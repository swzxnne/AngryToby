# Caps Lock Alert 😡

A tiny Chrome extension that watches what you type. If you type **3 all-caps words in a row** in any text field, an angry pixel boss slides out from the edge of the screen and yells **"STOP SHOUTING AT ME!"**

It runs on every page, stores nothing, and sends nothing anywhere — it's purely a bit of fun.

---

## Install (easy way — no coding required)

This extension isn't on the Chrome Web Store, so you install it as an "unpacked" extension. It takes about a minute.

1. Go to the [**Releases page**](../../releases/latest) and download the `caps-lock-alert.zip` file from the latest release.
2. **Unzip it.** You'll get a folder (e.g. `caps-lock-alert`).
3. Open Chrome and go to `chrome://extensions` (type it in the address bar).
4. Turn on **Developer mode** using the toggle in the top-right corner.
5. Click **Load unpacked** (top-left).
6. Select the unzipped folder.

That's it. Open any website, click into a text box, and type something like `HELLO WORLD NOW` — the boss will appear. 😡

> **Note:** Because this is an unpacked extension, Chrome may show a "Disable developer mode extensions" reminder on startup. That's normal for extensions not installed from the Web Store.

## Build from source (for developers)

Requires [Node.js](https://nodejs.org/) (which includes `npm`).

```bash
# 1. Clone the repo
git clone https://github.com/swzxnne/AngryToby.git
cd AngryToby

# 2. Install dependencies
npm install

# 3. Build the extension (bundles TypeScript -> dist/)
npm run build
```

This produces the `dist/` folder. Then load the extension in Chrome:

1. Go to `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select this project folder (the one containing `manifest.json`).

## How it works

| File | Purpose |
|------|---------|
| `manifest.json` | Manifest V3 config. Registers the content script and styles for all URLs. |
| `src/content.ts` | Listens for `input` events, checks if the last 3 words are all-caps, toggles the boss. |
| `src/styles.css` | Styles and animations for the slide-out boss. |
| `dist/` | Build output (generated by `npm run build`; not committed to git). |

### Permissions

The manifest requests only `activeTab`, and the content script runs locally in your browser. **No data is collected, stored, or transmitted.**
